# Frond Runtime

Frond Runtime is an Effect-powered frontend runtime for React and
MobX-facing application state. Pinna is its glitch-free reactive state
library, with Effect Schema classes for checked data.

## Website

- [frondruntime.dev](https://frondruntime.dev) - docs and package guides.
- [pinna.frondruntime.dev](https://pinna.frondruntime.dev) - Pinna's API reference and guides.

## Packages

### Frond

- [`@frondruntime/core`](https://github.com/frondruntime/frond/tree/master/packages/core) - runtime core primitives.
- [`@frondruntime/react`](https://github.com/frondruntime/frond/tree/master/packages/react) - React adapter for Frond Runtime.

### Pinna

- [`@frondruntime/pinna`](https://github.com/frondruntime/pinna/tree/main/packages/pinna) - boxes, computed values, keyed collections, and updates, with no Effect.
- [`@frondruntime/pinna-effect`](https://github.com/frondruntime/pinna/tree/main/packages/pinna-effect) - Pinna on Effect Schema: checked boxes, model classes, decoding, and Effect programs.
- [`@frondruntime/pinna-react`](https://github.com/frondruntime/pinna/tree/main/packages/pinna-react) - React hooks for Pinna.
- [`@frondruntime/pinna-core`](https://github.com/frondruntime/pinna/tree/main/packages/pinna-core) - the reactive graph, with no runtime dependencies.

## Repositories
